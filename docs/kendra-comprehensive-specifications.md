## 📦 エディション比較

### Developer Edition
- **月額料金**: $810 ($2.50/時間)
- **用途**: 概念実証（PoC）専用、本番環境非推奨
- **ストレージ制限**: 最大3GB (固定)
- **クエリ制限**: 0.05クエリ/秒 (固定)
- **データソース**: 最大5個
- **スケーラビリティ**: なし（容量追加不可）

### Basic Enterprise Edition
- **月額料金**: $1,000 ($7/時間)
- **用途**: 本番環境対応
- **ストレージ**: 30GB（追加容量可能、最大100ユニット）
- **クエリ制限**: 0.1クエリ/秒（追加容量可能）
- **データソース**: 最大50個
- **可用性**: 高可用性サービス

### GenAI Enterprise Edition （推奨）
- **月額料金**: $0.32/時間〜
- **用途**: 最高精度の検索体験
- **ストレージ**: 20,000文書または200MB/ユニット
- **クエリ制限**: 0.1クエリ/秒（8,000クエリ/日）
- **特徴**: 最新の情報検索技術とセマンティックモデル

## ⚠️ 制限事項・クォータ

### インデックス制限
| 項目 | Developer Edition | Enterprise Edition |
|------|-------------------|-------------------|
| **最大インデックス数** | 10個/アカウント | 10個/アカウント |
| **テキスト抽出容量** | 3GB/ユニット | 30GB/ユニット |
| **追加容量ユニット** | 不可 | 最大100ユニット |
| **データソース数** | 5個 | 50個 |

### 文書制限
- **最大文書サイズ**: 50MB
- **最大テキスト抽出**: 5MB/文書
- **S3プレフィックス**: 最大100個（アクセス制御リスト）
- **FAQ数**: 最大30個/インデックス
- **カスタムフィールド**: 最大500個

### クエリ制限
- **クエリ文字数**: 最大1,000文字
- **トークン数**: 30トークンで切り捨て
- **検索結果**: 最大100件/クエリ
- **同時接続数**: エディションにより異なる

### その他制限
- **シソーラス**: 1個/インデックス
- **Kendraエクスペリエンス**: 最大50個
- **カスタムドキュメント強化**: Lambda関数必要

## 🔐 セキュリティ・アクセス制御

### IAM統合
```json
{
  "認証方式": [
    "AWS IAMユーザー",
    "IAMロール",
    "フェデレーション認証",
    "SSO統合"
  ],
  "推奨ポリシー": {
    "読み取り専用": "AmazonKendraReadOnly",
    "完全アクセス": "AmazonKendraFullAccess"
  },
  "必要権限": [
    "kendra:Query",
    "kendra:Retrieve",
    "kendra:DescribeIndex",
    "s3:GetObject (データソース用)"
  ]
}
```

### 文書レベルセキュリティ
- **ユーザーコンテキストフィルタリング**
- **グループベースアクセス制御**
- **プリンシパル管理**（ユーザー/グループ）
- **文書属性によるフィルタリング**

### 暗号化
- **保存時暗号化**: AWS KMS
- **転送中暗号化**: TLS 1.2
- **キー管理**: AWS KMS カスタマーマネージドキー対応

### ベストプラクティス
```yaml
セキュリティ推奨事項:
  - 最小権限の原則を適用
  - MFA（多要素認証）の有効化
  - トラストポリシーでaws:sourceAccountを指定
  - 定期的なアクセスキーローテーション
  - IAMロール使用（IAMユーザーより推奨）
```

```yaml
実装例:
  - 自動カテゴリ分類
  - 感情分析
  - 重要度スコアリング
  - 多言語対応
```

### ブースティング機能
- **フィールドブースティング**: 特定フィールドの重み付け
- **期間ブースティング**: 新しい文書の優先度向上
- **重要度マッピング**: カスタム重要度設定
- **インデックスレベルオーバーライド**
